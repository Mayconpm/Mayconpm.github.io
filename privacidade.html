Política de Privacidade — Hermes Agent

Última atualização: 12 de outubro de 2026 · Página inicial

1. Sobre este aplicativo

O Hermes Agent ("o aplicativo") é um assistente pessoal auto-hospedado, desenvolvido e operado por Maycon Paqui Marciano para uso pessoal e privado. Ele roda em um servidor de propriedade do próprio desenvolvedor e é autorizado exclusivamente para a conta Google do seu proprietário. Não é um serviço público, não permite cadastro de outros usuários e não coleta dados de terceiros.

2. Dados do Google acessados

Com o consentimento explícito do usuário, concedido via OAuth 2.0, o aplicativo pode acessar as seguintes categorias de dados da conta Google autorizada (escopos de API do Google):

  • Gmail — leitura, organização, rotulagem, envio de mensagens e configuração de filtros/etiquetas.
  • Google Sheets — leitura e gravação em planilhas do usuário.
  • Google Drive e Google Docs — leitura, criação e edição de arquivos e documentos do usuário.
  • Google Calendar — leitura e criação de eventos na agenda do usuário.
  • Contatos do Google — leitura somente, para resolver destinatários de e-mail citados pelo usuário.

3. Finalidade do uso

Os dados são usados exclusivamente para executar as funções que o próprio usuário solicita ao assistente, entre elas:

  • identificar e apagar e-mails automáticos de verificação/códigos de acesso já expirados, e organizar a caixa de entrada;
  • manter atualizadas planilhas pessoais de controle (dieta, finanças e lista de compras);
  • ler, criar e editar documentos e arquivos de trabalho do usuário;
  • consultar a agenda e criar lembretes e eventos;
  • enviar mensagens em nome do usuário quando por ele solicitado.

Os dados não são usados para publicidade, perfilamento, treinamento de modelos, concessão de crédito ou qualquer finalidade diferente daquelas descritas acima.

4. Compartilhamento com terceiros

Os dados acessados não são vendidos, alugados, cedidos nem compartilhados com terceiros. O aplicativo também não transfere esses dados para plataformas de anúncios ou corretores de dados (data brokers). Os dados só podem ser divulgados se houver obrigação legal expressa.

5. Uso limitado dos dados do Google (Limited Use)

O uso, pelo Hermes Agent, de informações recebidas das APIs do Google está em conformidade com a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use). Em particular:

  • os dados são usados apenas para fornecer as funcionalidades visíveis e explícitas do aplicativo descritas nesta política;
  • os dados não são transferidos a terceiros, exceto quando necessário para fornecer ou melhorar essas funcionalidades, em conformidade com a lei, ou com o consentimento do usuário;
  • os dados não são usados para publicidade personalizada;
  • nenhuma pessoa pode ler esses dados, exceto o próprio usuário, ou por razões de segurança e obrigações legais.

6. Armazenamento e segurança

Os tokens de acesso (OAuth 2.0) e os dados processados ficam armazenados no servidor privado do próprio usuário, com permissões restritas de leitura no sistema de arquivos. As credenciais nunca são publicadas, compartilhadas ou enviadas a terceiros. As comunicações com as APIs do Google ocorrem por HTTPS.

7. Retenção e exclusão de dados

  • Revogação do acesso: o usuário pode revogar o acesso do aplicativo à sua conta Google a qualquer momento em myaccount.google.com/permissions. A revogação interrompe imediatamente novos acessos.
  • Exclusão dos dados locais: para solicitar a exclusão dos tokens e dos dados armazenados localmente, basta enviar um e-mail para o contato abaixo. A exclusão é feita em até 30 dias.
  • Retenção: os dados são mantidos apenas enquanto o aplicativo estiver em uso pelo proprietário. Após a revogação do acesso ou o pedido de exclusão, os tokens são apagados.

8. Cookies e rastreamento

Este site não utiliza cookies, rastreadores, ferramentas de analytics ou scripts de terceiros. O aplicativo não realiza rastreamento de navegação.

9. Menores de idade

O aplicativo não é destinado a menores de idade e não coleta intencionalmente dados de crianças.

10. Alterações desta política

Esta política pode ser atualizada para refletir mudanças no aplicativo ou na legislação aplicável. A data da última atualização é sempre indicada no topo desta página.

English version

Privacy Policy — Hermes Agent. Last updated: October 12, 2026. Hermes Agent is a private, self-hosted personal assistant built and operated by Maycon Paqui Marciano for his own personal use. It runs on the developer's own private server and is authorised only for his own Google Account; it is not a public service and it does not collect third-party data.

Google data accessed: Gmail (read, organise, label, send, manage filters), Google Sheets (read/write the user's own spreadsheets), Google Drive and Google Docs (read/create/edit the user's own files), Google Calendar (read/create the user's own events), and Google Contacts (read-only, to resolve e-mail recipients). Data is used solely to perform the tasks requested by that user.

Sharing: Google user data is never sold, rented, transferred or shared with third parties, and is not used for advertising or for training models. Hermes Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security: OAuth tokens and processed data are stored on the user's own private server with restricted file permissions and are transmitted over HTTPS.

Retention and deletion: access can be revoked at any time at myaccount.google.com/permissions. To request deletion of locally stored tokens and data, e-mail pm.maycon@gmail.com; requests are fulfilled within 30 days. This website uses no cookies, no analytics and no third-party scripts. Contact: pm.maycon@gmail.com.
